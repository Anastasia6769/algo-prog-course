«ПР1. Ответы на контрольные вопросы»

1.  В С# ошибки находятся сразу,программа не запустится пока не исправишь ошибки.В Python ошибки всплывают по факту

2.Сначала компилирует проект,потом запускает.

3.Папка bin/ готовые файлы для запуска, obj/ временные файлы,которые не хранятся в Git

4.commit сохраняется у меня на компьютере,push отправляется на сервер

5.+ склеивает кусочки строк, $"..." сразу вставляет переменные в строку.Удобнее $"..."

6.Дробную часть отбросит,чтобы получить дробь надо сделать хотя бы одно число double

7.Обычную переменную можно поменять,а const нельзя.Сonst используется если значение не изменится Например const int maxplayer = 4
